How to import your model:

veadotube mini
Follow the official instructions here > https://veado.tube/docs/usage/mini/#loadsave

PNGTuber Plus
Move the ".Save" file into PNGTuber Plus' data folder. You can location this folder by pressing Esc while the program is focused

RahiTuber	
Move the entire contents of the "RahiTuber Files" folder (NOT the folder itself) into the same directory as RahiTuber.exe.

Reactive by FugiTech
On the website (https://reactive.fugi.tech/) in the Models section click the + to create a new model. Name your model and add the speaking image into the "Speaking Image" space and the silent image to the "Inactive Image" space

Image Reaction Plugin for OBS
Download the plugin from the OBS Forums (https://obsproject.com/forum/resources/image-reaction.1342/) and install it. Add an Image Reaction source in OBS. Add the silent image into the "Image when silence" space and the speaking image to the "Image when sound" space
